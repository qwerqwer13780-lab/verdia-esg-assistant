# ESG knowledge base — recommended approved documents

Use authoritative source PDFs and rebuild the index after changes. The assistant should not rely on random web articles as its core knowledge base.

Recommended source families:

- GHG Protocol Corporate Standard
- GHG Protocol Scope 2 Guidance
- GHG Protocol Corporate Value Chain (Scope 3) Standard
- GHG Protocol Scope 3 Calculation Guidance
- Official CBAM guidance relevant to non-EU operators and embedded-emissions methodology
- IFRS/ISSB sustainability and climate disclosure materials that your project is actually implementing
- Relevant Egyptian environmental/climate reporting regulations or official guidance when the platform supports them
- Organization-approved methodology documents and emission-factor documentation

Keep the knowledge base versioned. When a regulatory or factor document changes, rebuild the index and record which source version/date is active.
